# Choose Your Role

Only one teammate should take each role. Make the site funny, but keep your changes inside the listed file or section during Round 2.

## Product Manager

Edit `index.html`:

- Replace **Totally Necessary™** with your startup name.
- Rewrite the short product description.
- Change the price.

Suggested commit: `Update product name and description`

## Feature Developer

Edit `index.html`:

- Replace the three feature names and descriptions.
- Add at least one emoji to each feature.

Suggested commit: `Add product features`

## Designer

Edit `styles.css`:

- Change the colors in `:root`.
- Change the button style.
- Add one hover effect.

Suggested commit: `Update site colors and buttons`

## Quality Engineer

Edit `script.js`:

- Replace the purchase messages.
- Add at least three possible messages.
- Make sure the button still works.

Suggested commit: `Improve purchase button messages`

## Bonus tasks

Finished early? Create a new branch for one of these:

- Add a customer testimonial.
- Add an FAQ question.
- Improve mobile styling.
- Find and fix an accessibility problem.
